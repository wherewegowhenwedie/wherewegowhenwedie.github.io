# wherewegowhenwedie.dev

The website of Where We Go When We Die, an independent game studio, and of its first game, UMBRA: ENDLESS.

Plain HTML and one stylesheet. No JavaScript, no cookies, no analytics and no trackers: each page's
Content-Security-Policy lets it load only files from this site.
